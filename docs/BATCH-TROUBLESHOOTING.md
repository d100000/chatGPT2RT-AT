# 批量提取进度停住：排查与恢复

[返回 README](../README.md) · [Token 提取指南](TOKEN-GUIDE.md) · [技术参考](REFERENCE.md)

## 2026-11-09 排查记录

收到的截图显示：批次共 904 个账号，91 个成功、183 个失败、630 个待处理；进度停在 274 / 904。摘要仍显示 3 个正在提取、0 个等待验证、627 个排队，但“正在处理的账号”详情区没有出现。

用户随后确认发生在 `https://tools.bob-api.com/`，观察到超过 5 分钟没有变化。后续截图还显示下载错误：“本浏览器尚未接收到这些结果，或缓存已过期。”检查用户原有线上标签页时，页面明确显示“批次不存在 正在重新获取批次状态。”，进度仍是 `274 / 904`。

**已确认一个可以复现该显示状态的前端缺陷，现场页面也已报告批次不存在。** 当前会话无法查询该批次，但尚未取得现场接口状态码、服务器访问日志或部署进程记录，不能据此断言是闲置清理、重启或多进程请求分配。观察到 5 分钟不变，不等于此前已有 10 分钟会话闲置。

页面中的“91 个成功 / 已接收”可能停留在旧渲染状态。下载错误表明此次下载没有取到对应缓存记录，不能再保证这 91 个结果仍可下载；应以实际下载成功为准。原有 30 分钟缓存有效期不因页面保留旧文字而延长。

## 已确认的代码路径

1. 服务端实时批次快照在同一把锁内生成统计和账号详情。有 3 个 `running` 账号时，`active_jobs` 应同时包含这 3 个账号。
2. 浏览器保存进度缓存时会移除验证挑战和运行详情，令 `active_jobs` 为空，但保留最近一次的状态和计数。
3. 旧版轮询遇到 HTTP 404，会直接显示这份缓存，再停止轮询。缓存里的 `running` 和 `queued` 不会收尾，因此界面一直显示“提取中”，实际状态却已不可知。

合成数据验证使用与截图相同的计数：实时快照包含 3 个运行详情；让会话闲置超过 600 秒后，任务接口返回 404。结合旧版前端分支，可得到相同的“计数未变、运行详情消失”表现。验证未使用真实账号。

没有发现“执行 274 个账号后停止”的数量限制。截图中某个账号的 2FA HTTP 403 是该账号的失败状态，不能单独解释整个队列停住。

## 哪些情况会让任务不存在

| 情况 | 现有行为 / 排查证据 |
| --- | --- |
| 会话长时间未访问服务 | 页面隐藏时暂停状态轮询；若没有其他页面或请求维持该会话，工作空间闲置 10 分钟后会被取消并清理 |
| 应用进程重启或退出 | Token 任务与尚未交接的结果仅保存在内存，重启后不能恢复 |
| 工作空间被清理 | 同一浏览器会话的“结束任务并清空”等操作会停止任务；其他人员应使用独立浏览器配置 |
| 多进程 / 多副本配置 | 任务不在进程间共享，请求被分配到其他进程时可能查不到任务；需核查实际 worker 数和访问日志 |

“页面在后台”本身不等于立即停止；是否达到闲置条件，取决于服务是否持续收到该会话的请求。能力评测和并发分析使用独立任务与历史机制，不适用这里的 Token 工作空间规则。

## 修复后的页面行为

- 批次状态接口确认任务不存在时，结束旧缓存中的运行与排队状态，显示任务已结束或过期，并释放开始新批次的控件。
- 已接收到浏览器的成功结果继续保留，可先下载。待处理账号不被当作成功，也不会自动重新提交凭据。
- 如果只是结果交接接口返回 404，先重新检查批次状态；批次仍存在时继续显示实时进度并重试交接，不把运行中的批次误判为结束。
- 清空任务或切换批次后的旧请求不能把已失效的进度重新显示回来。
- 浏览器缓存过期或被清除时，及时隐藏下载入口、旧的“已接收”数量和 RT 内容；实际服务器任务状态单独查询，不凭缓存过期取消任务。

此修复纠正状态显示与恢复入口，**不修改现有 10 分钟闲置清理策略，也不能恢复已经从服务器内存清除的账号凭据**。

## 遇到同类问题时

1. 先下载浏览器中已收到的成功结果，避免清除站点缓存或点击“结束任务并清空”。
2. 查看浏览器 Network 中批次状态请求的状态码。持续 200 且有运行详情时，检查对应账号阶段；404 应检查任务清理、服务重启或多进程部署；429 按提示等待。
3. 记录页面地址、停住时间、是否长时间切到后台、服务是否重启，以及脱敏后的状态码。不要分享 Cookie、CSRF、密码、2FA 密钥或完整 Token 响应。
4. 确认任务已经结束后，从原始账号列表整理未完成账号，重新导入。浏览器进度缓存不保存密码和 2FA 密钥，不能据此自动续跑。

旧版大批量 Token 提取期间保持至少一个对应页面可见，并避免电脑休眠或中途重启服务。长时间本地运行可使用 [分组 CLI](REFERENCE.md#本地分组提取)，逐条将成功结果保存到指定目录，避免依赖网页会话和浏览器缓存。不能仅靠页面保留的计数判断任务仍在运行或 Token 仍可下载。
